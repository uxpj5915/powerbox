## DC99 的三网 CN2 GIA 回程，实际表现怎么样

线路是这个套餐的核心卖点。搬瓦工常规套餐里，走 CN2 GIA 的机型年付六七十美元起步，PowerBox 把这个门槛拉到了 45 美元。

从已公开的第三方实测数据看（2025 年初的测评）：

- **三网回程全部确认 CN2 GIA**，电信回程在广州接入电信骨干、全程走 59.43 精品网无绕路，线路标记“精品线路”；联通在广州接入联通骨干、最后一跳到深圳；移动在广州转移动网络。测评原话是“三网回程都确认是 CN2 GIA，这点没有虚标”。
- 延迟：电信约 134–150ms，移动约 160ms，联通约 170ms，整体在 130–170ms 区间，属美国西海岸机房正常水平，丢包率接近零。
- 性能：sysbench 单线程 1094 分，硬盘 4K 随机读写 68.4MB/s，内存单线程读 22.9GB/s。跑 WordPress、静态站、轻量开发环境都够用。
- 流媒体：YouTube Premium 完全解锁、Disney+ 美区、TikTok 美区、Netflix 仅限自制剧。

需要说明的是，这是发布初期的单点实测，机房负载会随时间变化，CN2 GIA 也不等于永远不堵。但相比同价位走普通 163 骨干线路的机型，DC99 的下限确实高，这也是 Box 系列每次上架就被抢光的原因。
